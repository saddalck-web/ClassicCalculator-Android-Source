# الآلة الحاسبة الكلاسيكية — Android / Kotlin

تطبيق أندرويد بسيط بواجهة داكنة، يعمل دون إنترنت، ويستخدم `BigDecimal` بدلاً من `Double` في الحسابات لتقليل أخطاء الفاصلة العائمة.

## الوظائف
- جمع وطرح وضرب وقسمة مع أولوية الضرب والقسمة.
- عمليات عشرية وأرقام سالبة.
- الجذر التربيعي والتربيع والمقلوب والنسبة المئوية وتغيير الإشارة.
- ذاكرة MC / MR / M+ / M− / MS.
- سجل آخر 30 عملية.
- رسائل خطأ للقسمة على صفر والصيغ غير الصحيحة.

## فتح وبناء التطبيق
1. فك ضغط الملف.
2. افتح مجلد `ClassicCalculator` باستخدام Android Studio.
3. اسمح بمزامنة Gradle وتنزيل إضافات Android المطلوبة.
4. من قائمة **Build > Build APK(s)** أنشئ ملف APK.
5. عادةً ستجد النسخة التجريبية في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات
- تم تجهيز ملفات المصدر، لكن لم يتم إنشاء APK أو إجراء بناء فعلي في هذه البيئة لعدم توفر Android SDK وGradle.
- الحسابات تستخدم دقة داخلية من 34 رقماً مع التقريب HALF_EVEN عند الحاجة؛ القسمة العشرية غير المنتهية تُقرّب لهذه الدقة، كما هو متوقع في الحاسبات الرقمية.
- هذه نسخة أولية قابلة للتطوير، ويُنصح باختبارها على جهاز فعلي قبل النشر.
